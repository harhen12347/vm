Format and compatibility

GX is normally a FlashForge binary wrapper containing G-code and an embedded thumbnail—not an original CAD/STL archive. This tool extracts only metadata present in that payload and creates an STL from extruding movements. The STL is a physical-toolpath approximation, not recovered source geometry. Native FlashPrint FCFG generation is unsupported. The separate JSON metadata download is not an FCFG file and must not be renamed as one.
